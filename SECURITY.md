# Política de seguridad

**Español** · [English](#english)

PDFiu procesa documentos PDF locales, certificados digitales y archivos externos. Si encuentras una vulnerabilidad de seguridad (por ejemplo, ejecución arbitraria de código, problemas en la validación del canal de actualizaciones, fugas de datos o fallos en el manejo de certificados), **no la publiques en una incidencia pública**.

## Cómo informar de una vulnerabilidad

- Utiliza la opción **Report a vulnerability** (GitHub Security Advisories) en la pestaña **Security** del repositorio `mfcb89/pdfiu`.
- Incluye la versión de PDFiu, el sistema operativo, los pasos para reproducir el problema y, si es posible, un PDF de prueba sintético sin datos confidenciales.

## Versiones con soporte

Actualmente se mantienen únicamente la versión más reciente publicada y la rama principal.

---

## English

PDFiu processes local PDF files, digital certificates, and external files. If you discover a security vulnerability (for example, arbitrary code execution, update-channel validation flaws, data leaks, or certificate handling issues), **please do not report it in a public issue**.

### Reporting a vulnerability

- Use **Report a vulnerability** (GitHub Security Advisories) under the **Security** tab of `mfcb89/pdfiu`.
- Include your PDFiu version, operating system, reproduction steps, and if possible a synthetic test PDF without private data.

### Supported versions

Only the latest published release and the default branch currently receive security fixes.
