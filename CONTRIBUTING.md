# Contribuir a PDFiu

**Español** · [English](#contributing-to-pdfiu)

- Abre una [incidencia](https://github.com/mfcb89/pdfiu/issues) con la versión de PDFiu, tu sistema operativo, los pasos para reproducir el problema y lo que esperabas que ocurriera. Si hace falta un PDF, adjunta un ejemplo sintético o anonimizado. Los documentos, las capturas, los certificados y las contraseñas reales deben quedarse fuera de la incidencia pública.
- Crea una rama para tu cambio y ejecuta PDFiu desde el código. En la propuesta de cambios, explica qué cambiaste y cómo lo probaste. [Ejecutar desde el código](README.md#ejecutar-desde-el-código)
- Para cambios de interfaz, comprueba español e inglés. Las cadenas se definen en el código y su traducción inglesa en [el catálogo](assets/languages/en.json).
- Si añades una dependencia o un recurso externo, registra su versión y el aviso de licencia. [Avisos de terceros](THIRD_PARTY_NOTICES.md)

## Contributing to PDFiu

- Open an [issue](https://github.com/mfcb89/pdfiu/issues) with your PDFiu version, operating system, steps to reproduce, and expected result. If you need to show a PDF, attach a synthetic or anonymized example. Keep real documents, screenshots containing private data, certificates, and passwords out of public issues.
- Create a branch for your change and run PDFiu from source. In your pull request, explain what changed and how you tested it. [Run from source](README.en.md#run-from-source)
- Check both Spanish and English for UI changes. The source strings live in code and their English translations are in [the catalog](assets/languages/en.json).
- If you add a dependency or an external asset, record its version and license notice. [Third-party notices](THIRD_PARTY_NOTICES.md#english)
